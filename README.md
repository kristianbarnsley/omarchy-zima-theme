# Omarchy Zima Blue Theme 
An Omarchy theme based on the Zima Blue episode of Love, Death & Robots anthology

## Install

```bash
omarchy theme install https://github.com/kristianbarnsley/omarchy-zima-theme
```


## Omarchy Quatro 
This theme was made for Omarchy Quatro, and may not work fully with legacy Omarchy systems
